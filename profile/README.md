# FetchMCP

Fetch MCP setup, client by client, checked and dated.

- **Website:** [fetchmcp.net](https://fetchmcp.net)
- **Blog:** [fetchmcp.net/blog](https://fetchmcp.net/blog) · **Guides:** [fetchmcp.net/guides](https://fetchmcp.net/guides)
- **Docs:** [fetchmcp.net/docs](https://fetchmcp.net/docs)
- **CLI:** [`fetchmcp`](https://github.com/fetchmcp-net/cli), live web pages as Markdown from your terminal ([docs](https://fetchmcp.net/docs/cli), [npm](https://www.npmjs.com/package/@fetchmcp-net/cli))

```bash
npx @fetchmcp-net/cli fetch https://example.com -o text
```

A [Teneo Labs](https://fetchmcp.net/imprint) project, built on the [Live Web Data API](https://livewebdata.com).
